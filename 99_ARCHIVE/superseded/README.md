# Dayjoy Phase 1 Baseline

This package contains the frozen Phase 1 baseline for the Dayjoy AI knowledge repository.

## Included folders
- `source/baseline-v1/raw/` — approved source documents copied without modification
- `source/baseline-v1/derived/` — current derived CSV/XLSX datasets copied without modification
- `qa/baseline-v1/` — manifest and baseline summary

## Baseline rule
Do not edit files in this baseline directly. Any changes must be made in a new working or versioned folder, then re-published with a new manifest.
