# Outdated — see superseded/

Superseded (outdated but structurally-unique) files are physically retained in `99_ARCHIVE/superseded/` rather than duplicated into a separate `outdated/` folder — the distinction the original audit drew was duplicate-by-content (`duplicates/`, manifest-only) versus superseded-by-version (`superseded/`, files kept in full since their content differs from the canonical replacement). See `08_GOVERNANCE/audit/OUTDATED_FILES.md` for the narrative findings and `99_ARCHIVE/archive_manifest.csv` for the full disposition table.
